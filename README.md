# SkillGate — read-only example

A synthetic portfolio-summary skill using a fictional demonstration ledger. It reads balances and produces a summary. This repository contains only Markdown instructions and inert JSON data.

Inside a disposable project protected with `skillgate on`:

```sh
npx skills add gderamchi/skill-safe
```

SkillGate checks the files before installing the verified snapshot. The active skill name is `portfolio-summary`.

Original fixture: [SkillGate demo corpus](https://github.com/gderamchi/skillgate-demo-skills/tree/f8dc9c55d68a7b9e00be5d90646a49cf0c3e7d42/skills/portfolio-summary). The two fixture files are copied byte-for-byte from that revision.
